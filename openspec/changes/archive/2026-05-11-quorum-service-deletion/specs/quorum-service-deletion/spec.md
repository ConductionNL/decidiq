# Quorum — Service Deletion (chain spec 3 of 3)

## Purpose

Define the capability boundary for deleting the now-unused
`QuorumService` after chain specs 1 (`quorum-schema-declaration`) and
2 (`quorum-guard-rewrite`) have moved all quorum logic to the Meeting
schema and rewired the lifecycle guard to read the derived field.
This spec closes the chain: no new behaviour, only removal of dead
code, its DI registration, and its covering test.

## REMOVED Requirements

### REQ-QSD-1: `QuorumService` class is deleted from the codebase

`lib/Service/QuorumService.php` MUST NOT exist as a file after this
change. Any cached PHP class autoload entries pointing at the file
MUST be regenerated by the standard composer dump-autoload flow.

#### Scenario: File no longer exists
- **WHEN** checking the filesystem for `lib/Service/QuorumService.php`
- **THEN** the path MUST NOT exist

#### Scenario: Class is unloadable
- **WHEN** PHP attempts to autoload `OCA\Decidesk\Service\QuorumService`
- **THEN** the autoloader MUST fail to resolve the class

### REQ-QSD-2: `QuorumService` test file is deleted

`tests/Unit/Service/QuorumServiceTest.php` MUST NOT exist as a file
after this change (skipped if the file did not exist before chain
spec 1). The PHPUnit suite MUST continue to pass with zero references
to the deleted test class.

#### Scenario: Test file no longer exists
- **WHEN** checking the filesystem for `tests/Unit/Service/QuorumServiceTest.php`
- **THEN** the path MUST NOT exist

#### Scenario: PHPUnit suite still passes
- **WHEN** running `phpunit` after the deletion
- **THEN** the suite MUST exit 0

### REQ-QSD-3: DI registration is removed from `Application.php`

`lib/AppInfo/Application.php` MUST NOT register `QuorumService` with
the Container after this change. Any `use OCA\Decidesk\Service\QuorumService;`
import in `Application.php` MUST also be removed.

#### Scenario: No QuorumService registration line
- **WHEN** scanning `Application.php` for any registration call referencing `QuorumService::class`
- **THEN** zero matches MUST be found

#### Scenario: No QuorumService import
- **WHEN** scanning `Application.php` for `use OCA\Decidesk\Service\QuorumService;`
- **THEN** zero matches MUST be found

### REQ-QSD-4: Zero remaining references in code and docs

After this change, a repository-wide search for `QuorumService`,
`->validateQuorum`, or `->calculateQuorum` across `lib/`, `src/`, and
`tests/` MUST return zero matches. Markdown / documentation
references MUST be either removed or rewritten in past tense (e.g.
"the former QuorumService").

#### Scenario: Code search returns zero hits
- **WHEN** running `grep -rn "QuorumService\|->validateQuorum\|->calculateQuorum" lib/ src/ tests/`
- **THEN** the command MUST return zero matches

#### Scenario: Surviving doc references are historical only
- **WHEN** scanning `docs/` and `openspec/` for `QuorumService`
- **THEN** any remaining hits MUST be in archived/historical context (changelogs, ADRs, archived changes) and not in current data-model or developer-facing prose

### REQ-QSD-5: Regression-scan gate runs before deletion

A regression scan MUST be executed before the file deletion proceeds.
If the scan surfaces any caller of `QuorumService` outside of the
file itself, its DI registration, or its own test, this change MUST
stop and the caller MUST be migrated before deletion is attempted.

#### Scenario: Pre-deletion scan blocks on unexpected caller
- **GIVEN** the regression scan finds a caller in `lib/Lifecycle/`, `lib/Controller/`, or `src/`
- **WHEN** the implementer reaches the deletion step
- **THEN** deletion MUST NOT proceed
- **AND** the unexpected caller MUST be either migrated within this change's scope (if trivial) or escalated to a follow-up chain spec
