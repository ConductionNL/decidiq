## 4. Result publication (OpenCatalogi / published-predicate)
- [x] 4.1 Anonymous-visibility leg built via the RBAC published-predicate. The earlier "BLOCKED — OR MagicMapper `published` allowlist gap" was a MISDIAGNOSIS: `@self.published` is deprecated/removed from OpenRegister, and decidesk participation objects are register-owned objects on the normal RBAC save path (never magic-mapped). - [x] 4.3 OpenCatalogi routing: when installed and a target catalog is configured, create the publication in that catalog (with `publicatiedatum` set); degrade with a staff-visible warning when absent (`isOpenCatalogiInstalled()` + `routeToOpenCatalogi()`).
- [x] 4.4 Per-reaction opt-in publication by moderators (`publishReaction()` sets `publicatiedatum` on a single approved reaction; never blanket; the ConsultationReaction read rule also requires `moderationStatus: approved`).
